# 02 — In Good Hands

**Christian's complete product journey.** [Open](https://clschulzer.github.io/Aloha-Robotics-HH2.0/ASTRA/versions/02-christian/) · [Script](SCRIPT.md) · [Presenter](../presenter.html?v=02-christian)

This is a deliberate alternative to Ember. It follows Christian's current storyboard and renders a local copy of his actual `pitch-demo-christian` template. The phone, maintenance-priority queue, operating plan, request, robot map, checking agent, start wizard and thank-you loop come from the team's existing code.

The film and short ember landing lead into a human statement, three moods, the distinction between priority and timing, then the complete service journey. The final three pillars connect emotional care, coordination and physical help.

## What changed

- Re-timed the storyboard to preserve the entire original 30.44-second film. It still ends at 180 seconds.
- Removed the persistent act labels and slide counters from the projected product view.
- Gave the phone and surrounding typography more space. Simplified the priority slide and widened the important labels.
- Unified the embedded product, outer stage, notes and clicker under one cue clock.
- Added scene-aware sound, a short dark “Now.” transition and an animated three-pillar conclusion.
- Preserved the mission's map and step-by-step checking pattern.
- Added same-origin embedding controls and pausable child timers; the embedded demo cannot advance independently of the stage.

## Evidence corrections

The original template uses an invented 18-minute update. This copy uses an explicitly illustrative 120-minute installation and consistent later report times. The stage compresses that wait. It does not promise a shorter real installation.

Location-match percentages were removed. The report returns a service result for team review rather than declaring clinical release. The robot camera is labelled simulated. Hardware docking, wake and the clinical start interface remain proposed integration points.

The product walk-through is scripted. The separate tested `IAPlanner` remains the team's functional planning core; this version does not claim that the template's fixed example is a live hospital optimization.

Use **Present live** and the right arrow/clicker, or **Watch 3-minute preview**. `N` notes, `P` pause, `S` optional sound, `F` fullscreen, `Home` reset. Run from a local HTTP server or GitHub Pages. The complete embedded template remains in [demo/](demo/) for independent inspection.
