# C-ARMAGOTCHI-Bilder

Figuren aus der Teampräsentation C-ARMAGOTCHI im Repo
[mteyra/Aloha-Robotics-HH2.0](https://github.com/mteyra/Aloha-Robotics-HH2.0)
(`CARMAGOTCHI_Web_Pitch/pitch/assets/`, Stand 260b4e1). Unverändert übernommen, damit der
Begleiter im Klickdummy dieselben Figuren zeigen kann wie der Pitch.


| Datei | Figur | Bedeutung im Pitch |
| :--- | :--- | :--- |
| `ketty.webp` | KettyBot, Service-Roboter mit Kabel | Der Roboter, der zum Gerät kommt |
| `bliss.webp` | C-Bogen glücklich | Nach erledigtem Routine-Service, alles synchron |
| `lonely.webp` | C-Bogen traurig, kein Netz | Lange nicht verbunden |
| `manic.webp` | C-Bogen außer Rand und Band | Chaos ohne gesteuerte Updates |
| `update.webp` | C-Bogen beim Update | Update läuft |
| `rollback.webp` | C-Bogen mit „ROLLBACK…“ | Update wird zurückgerollt |
| `failure.webp` | C-Bogen mit Warnsymbol | Fehler bei der Wiederherstellung |

- Je Figur zwei Fassungen, 940 × 940 px: `<name>.webp` mit transparentem Hintergrund,
  `<name>_white.webp` auf Weiß. `uebersicht.png` ist eine Kontaktbogen-Vorschau.
- Die Figuren tragen das Siemens-Healthineers-Logo. Nur für Hackathon-Pitch und Demo verwenden,
  nicht außerhalb veröffentlichen.
