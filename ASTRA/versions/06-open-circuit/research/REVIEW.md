# Design review — Open Circuit

## A different job for these three minutes

The user explicitly requested a pure technical version. This cut therefore begins with the system, without replaying the comedy movie or walking through the character states. That is a deliberate difference from the six pitch versions built around the movie.

The technical story is “suggestion → eligibility → permission → accountable handoff.” It gives the audience enough to ask informed questions without trying to read the entire specification from the stage.

## What carries forward from the earlier versions

OPUS's strongest motion makes a transition feel inevitable. The first scene separates a stack into input, rule and human layers. Later paths grow toward the component being introduced. Those motions carry meaning; the rest of the surface stays still.

The ASTRA versions' strongest property is legibility. The stage uses one headline, a small amount of explanatory text and one dominant diagram. Code appears as structured output, a gate and executable evidence, rather than a full editor screenshot.

Constellation's performance review also informs this version: perspective is not left on a large, continuously changing board. The engineering scenes are flat compositions; only the introductory stack is transformed.

## Decisions and review corrections

- The candidate matrix is computed from actual scorer results. Rejected cells recede, the surviving list settles, and a structured proposal appears.
- The result lists the real selected device and backup. It does not display the source model's illustrative percentage as a clinical prediction.
- The six-condition gate is a circuit metaphor with actual behavior behind it. Blocked buttons cannot be clicked; eligible states do not automatically start.
- Built code and proposed integration are distinguished in the diagram. The rule-core module has a different treatment inside the proposed hospital node.
- Permission is presented as a contract bound to facts. The “new plan version” frame explains invalidation visually without pretending cryptographic enforcement already exists.
- The final evidence grid runs checks on the same functions used for the proposal.

Initial browser review found input connectors with guessed vertical coordinates and two transport captions crossing paths. The input anchors now use measured card geometry. The captions are outside the path or have a clean label surface. The vendor block was enlarged to fit its content, and the structured-result caption was moved below the card.

## Delivery

The code stays within this version's folder. Source files from the team are copied, not modified. The shared ASTRA review tools were extended to verify an eligible-but-not-started state and a real click on the local simulation button.

The complete script, source analysis and browser evidence accompany the presentation so technical Q&A does not depend on remembering the build conversation.
