## 0:09–0:20 — The implemented core

We built the browser workflow and a deterministic JavaScript rule core. Theatre plans, device state, usage history and alarms become structured inputs.

## 0:20–0:33 — Reject first

First, reject collisions, thin data, motion updates, unavailable people and missing backup. Missing information never means a free machine.

## 0:33–0:45 — Rank what survives

The team’s scorer then ranks legal windows using unplanned use, emergency demand and case overrun. These inputs are synthetic; clinical calibration is still ahead.

## 0:45–0:56 — An inspectable result

The result names the device, window and replacement. An explanation can describe that result. It cannot relax the rules.

## 0:56–1:04 — Device in use

This is the actual start predicate. A device in use blocks the proposal.

## 1:04–1:12 — Emergency alarm

An alarm closes the gate, even when the rest looks ready.

## 1:12–1:20 — Package recalled

A recalled package also blocks it. A persuasive explanation changes nothing.

## 1:20–1:30 — Eligible is not started

## 1:30–1:42 — The proposed pilot stack

## 1:42–1:52 — An approved package route

The node initiates an approved connection to teamplay Fleet and remote services. Packages come inward; permitted technical status goes back.

## 1:52–2:03 — Transport, not trust

The robot adapter uses the proposed ROS 2 and Nav2 layer. It carries power and approved data to one device. The handoff is not a network bridge.

## 2:03–2:13 — Close the loop

Status and logs return to the hospital node. Exceptions go to a responsible person. Device-side interfaces and power engineering still need validation with Siemens.

## 2:13–2:23 — Bind the permission

The proposed authorization contract binds a person, a device, a package and a plan version. Manufacturer signatures establish package origin; hospital identity establishes permission.

## 2:23–2:33 — Invalidate the old decision

Change the window, recall the package or lose current readiness, and the old permission cannot authorize a new start.

## 2:33–2:43 — Run the invariants
