# Share C-ARMAGOTCHI

These codes open the public mobile app directly:

**https://clschulzer.github.io/Aloha-Robotics-HH2.0/CARMAGOTCHI_APP/**

- **[qr.png](qr.png)** — high-resolution black-and-white QR for slides and screen sharing.
- **[qr.svg](qr.svg)** — scalable vector QR for print or design tools.
- **[qr-card.png](qr-card.png)** — print-friendly card with the QR and a short invitation.
- **[verification.json](verification.json)** — independent decoding checks and file hashes.

The QR is generated by **python-qrcode 8.2**, with **H** error correction and a
four-module white quiet zone. No logo covers any QR modules. The PNG uses integer
20-pixel modules. Do not crop its white border when placing it in a presentation.

The QR PNG and the complete card were independently decoded with **ZXing-C++
3.1.1**, both at original size and at reduced display sizes (320-pixel QR and
600-pixel-wide card). Every check must resolve to the exact URL above.

## Regenerate

The script requires Python, `fc-match` for the printable card's system font, and
the libraries below. This example uses uv's isolated environment:

```sh
uv run --no-project --python 3.12 --with qrcode==8.2 --with Pillow==13.0.0 --with zxing-cpp==3.1.1 python CARMAGOTCHI_APP/share/generate.py
```

On NixOS, the ZXing native extension also needs the GCC `libstdc++` runtime
available through `LD_LIBRARY_PATH`. This affects regeneration only, not viewing
or scanning the static assets.

The code is static: the app URL does not expire and no third-party QR redirect
service is involved. Availability follows the repository's GitHub Pages
deployment.
